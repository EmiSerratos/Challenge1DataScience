# 📊 AluraStore Serratos - Análisis de Tiendas

Este notebook tiene como objetivo **analizar el desempeño de cuatro tiendas** pertenecientes al Sr. Juan, con el fin de recomendar cuál de ellas debe vender. El análisis está basado en múltiples variables clave de negocio.

---

## 🧠 Objetivo del Proyecto

Realizar un análisis completo de datos operativos y comerciales para determinar cuál tienda representa **la opción menos estratégica para conservar**, considerando:

- Ingresos generados.
- Calificaciones de los clientes.
- Rotación de productos.
- Distribución de ventas por categoría.
- Costos operativos (envío).

---

## 📂 Estructura del Proyecto

### Contenido del Notebook

- **Carga y exploración de datos**: Importación de archivos CSV y visualización inicial.
- **Análisis de ingresos**: Comparación de ingresos por tienda.
- **Análisis de calificaciones**: Evaluación de la satisfacción del cliente.
- **Ventas por categoría**: Evaluación del portafolio y diversificación.
- **Productos más/menos vendidos**: Evaluación de rotación.
- **Costos de envío**: Comparativa de costos logísticos.
- **Recomendación final**: Tienda sugerida para venta, basada en todos los indicadores.

---

## 📈 Herramientas Utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook (Google Colab)

---

## ✅ Recomendación Final

> Basado en el análisis integral, se recomienda vender **Tienda 4**, ya que presenta menor ingreso total, rotación limitada y menor proyección estratégica a futuro.
